나만의 프롬프트 관리 프로그램

터미널에서 메뉴 번호를 입력해 프롬프트를 관리하는 콘솔 프로그램입니다.
프롬프트를 카테고리별로 등록하고, 검색하고, 즐겨찾기로 관리할 수 있습니다.

## 실행 방법

\`\`\`bash
python main.py
\`\`\`

## 기능 목록

- 프롬프트 추가
- 프롬프트 목록 보기
- 카테고리별 조회
- 프롬프트 검색
- (작업 중) 프롬프트 상세 보기
- (작업 중) 즐겨찾기 관리
- (작업 중) 즐겨찾기 목록

## 카테고리 종류

텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화, 기타
